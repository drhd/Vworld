# 🤖 دبیرا (Dabira) — دستیار همیشه‌حاضر جلسات

**صوت جلسه را بفرست، صورت‌جلسه رسمی تحویل بگیر.**

دبیرا یک ایجنت هوش مصنوعی است که فایل صوتی جلسه را در تلگرام می‌گیرد و:
1. 🎙️ متن کامل جلسه را پیاده می‌کند (فارسی/انگلیسی — تشخیص خودکار زبان)
2. 📝 صورت‌جلسه استاندارد و رسمی می‌نویسد (قالب‌های بیزینسی یا قالب اختصاصی شما)
3. 📄 فایل `.md` نهایی را با تاریخ شمسی تحویل می‌دهد
4. 💬 و یک چت‌بات هوشمند پاسخگو هم هست

**همه‌چیز ۱۰۰٪ رایگان** — بدون کارت بانکی، بدون کردیت، بدون سرور پولی:

| نقش | سرویس | هزینه |
|---|---|---|
| صوت → متن | Groq Whisper large-v3 | رایگان |
| نگارش صورت‌جلسه + چت | Groq Llama 3.3 70B (پشتیبان: Gemini Flash) | رایگان |
| هاست (بدون خواب، بدون لگ) | Cloudflare Workers | رایگان |
| رابط کاربری | Telegram Bot | رایگان |

## ساختار پروژه

```
dabira/
├── worker/
│   ├── worker.js          ← مغز دبیرا (کل ایجنت در یک فایل — قابل پیست در داشبورد Cloudflare)
│   └── wrangler.toml      ← فقط برای دیپلوی با خط فرمان (اختیاری)
├── n8n/
│   └── dabira-n8n-free.json  ← نسخه n8n با APIهای رایگان (جایگزین ورک‌فلوی قدیمی OpenAI)
├── templates/
│   └── edge.fa.md         ← جای قالب «متد edge» شما (با /learn به ربات آموزش داده می‌شود)
└── docs/
    ├── 01-rahnama-ghadam-be-ghadam.fa.md  ← 🚀 آموزش کامل راه‌اندازی، کلیک‌به‌کلیک
    └── 02-roadmap.fa.md                    ← نقشه راه: وب‌اپ فروش، اشتراک، اپ موبایل
```

## شروع سریع

راهنمای کامل: [docs/01-rahnama-ghadam-be-ghadam.fa.md](docs/01-rahnama-ghadam-be-ghadam.fa.md)

خلاصه‌ی مسیر (~۳۰ دقیقه):
1. ساخت ربات با @BotFather → گرفتن `BOT_TOKEN`
2. ثبت‌نام رایگان در console.groq.com → گرفتن `GROQ_API_KEY`
3. ساخت Worker رایگان در Cloudflare → پیست کردن `worker/worker.js`
4. وارد کردن متغیرها + ساخت KV با نام `DABIRA_KV`
5. اتصال وب‌هوک تلگرام با یک لینک در مرورگر
6. 🎉 ویس بفرست و صورت‌جلسه تحویل بگیر

## دستورات ربات

| دستور | کار |
|---|---|
| `/start` `/help` | معرفی و راهنما |
| `/template` | انتخاب قالب: استاندارد، استارتاپ، اداری، هیئت‌مدیره، فروش، آموزشی |
| `/learn` + نمونه | یادگیری قالب اختصاصی شما (مثل متد edge) |
| `/project نام` | پروژه‌بندی و آرشیو فایل‌ها |
| `/lang fa/en/auto` | زبان خروجی (fa = همیشه فارسی حتی با ترجمه) |
| `/id` | شناسه چت (برای تنظیم مالک) |
| هر متن دیگر | گفتگو با چت‌بات دبیرا |
