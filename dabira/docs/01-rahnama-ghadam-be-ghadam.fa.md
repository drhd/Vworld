# 🚀 راهنمای راه‌اندازی دبیرا — قدم‌به‌قدم، کلیک‌به‌کلیک

این راهنما برای کسی نوشته شده که **هیچ دانش فنی ندارد**. فقط مرحله‌به‌مرحله جلو برو.
کل مسیر حدود **۳۰ دقیقه** وقت می‌برد و **صفر تومان** هزینه دارد — نه کارت بانکی می‌خواهد، نه کردیت.

---

## نقشه کلی (چی به چی وصل می‌شود؟)

```
شما در تلگرام ویس جلسه می‌فرستید
        ↓
ربات تلگرام «دبیرا»
        ↓
Cloudflare Worker  ←  اینجا مغز دبیرا زندگی می‌کند (هاست رایگان، بدون خواب)
        ↓
Groq Whisper  ←  صوت → متن (رایگان، فارسی و انگلیسی، تشخیص خودکار)
        ↓
Groq Llama / Gemini  ←  متن → صورت‌جلسه رسمی (رایگان)
        ↓
فایل .md با تاریخ شمسی در تلگرام تحویل داده می‌شود
        ↓ (فقط برای مالک)
ذخیره خودکار در مخزن GitHub → همگام‌سازی با Obsidian
```

---

## مرحله ۱ — ساخت ربات تلگرام (۵ دقیقه)

1. تلگرام را باز کن و در جستجو بنویس: **@BotFather** (تیک آبی دارد).
2. روی **Start** بزن.
3. بنویس: `/newbot` و بفرست.
4. اسم نمایشی ربات را بنویس، مثلاً: `دبیرا | دستیار جلسات`
5. حالا یک **username** می‌خواهد که باید به `bot` ختم شود، مثلاً: `DabiraAIBot`
   (اگر گفت تکراری است، یک عدد یا کلمه اضافه کن: `DabiraProBot`)
6. BotFather یک پیام تبریک می‌فرستد که داخلش یک **توکن** هست، شبیه این:
   ```
   7123456789:AAHfK9x2mP...
   ```
   ⚠️ **این توکن را کپی کن و یک جای امن نگه دار.** این «کلید» ربات توست — به هیچ‌کس نده.

---

## مرحله ۲ — گرفتن کلید رایگان Groq (۵ دقیقه)

Groq همان سرویسی است که هم صوت را به متن تبدیل می‌کند (Whisper) و هم صورت‌جلسه را می‌نویسد (Llama). **کاملاً رایگان و بدون کارت بانکی.**

1. برو به: **https://console.groq.com**
2. روی **Sign Up** کلیک کن → با **حساب گوگل** (Gmail) ثبت‌نام کن (سریع‌ترین راه).
3. بعد از ورود، از منوی سمت چپ روی **API Keys** کلیک کن.
4. روی دکمه **Create API Key** کلیک کن.
5. یک اسم بده (مثلاً `dabira`) و **Submit** بزن.
6. کلیدی شبیه `gsk_...` نشان می‌دهد. ⚠️ **همین لحظه کپی‌اش کن** — دیگر نشانش نمی‌دهد!

> سهمیه رایگان: حدود ۲۰۰۰ فایل صوتی در روز و ۲ ساعت صوت در هر ساعت — برای شروع کار و حتی ده‌ها مشتری کافی است.

---

## مرحله ۳ — (اختیاری ولی پیشنهادی) کلید رایگان Gemini (۳ دقیقه)

اگر Groq شلوغ شد، دبیرا خودکار می‌رود سراغ Gemini. این هم رایگان است.

1. برو به: **https://aistudio.google.com**
2. با حساب گوگل وارد شو.
3. روی **Get API key** کلیک کن (بالا یا در منو).
4. **Create API key** → کلید `AIza...` را کپی کن و نگه دار.

---

## مرحله ۴ — راه‌اندازی هاست رایگان Cloudflare (۱۰ دقیقه)

چرا Cloudflare؟ چون تنها هاست رایگانی است که: **نمی‌خوابد** (برخلاف Render و Glitch)، **لگ ندارد**، **کارت بانکی نمی‌خواهد**، و روزی ۱۰۰,۰۰۰ درخواست رایگان می‌دهد.

### ۴-۱) ساخت حساب
1. برو به: **https://dash.cloudflare.com/sign-up**
2. با ایمیل ثبت‌نام کن و ایمیل تأیید را باز کن و لینکش را بزن.

### ۴-۲) ساخت Worker
1. بعد از ورود، از منوی سمت چپ روی **Workers & Pages** کلیک کن.
2. روی دکمه آبی **Create** کلیک کن.
3. **Create Worker** را انتخاب کن (نه Pages).
4. اسمش را بگذار: `dabira` → روی **Deploy** کلیک کن (فعلاً کد پیش‌فرض را دیپلوی می‌کند، اشکال ندارد).
5. حالا روی **Edit code** کلیک کن.
6. **تمام کد داخل ادیتور را پاک کن** و به‌جایش کل محتوای فایل `worker.js` (از پوشه `dabira/worker/` همین پروژه) را **کپی/پیست** کن.
7. دکمه **Deploy** (بالا سمت راست) را بزن.
8. آدرس Worker خودت را یادداشت کن؛ شبیه این است:
   ```
   https://dabira.YOURNAME.workers.dev
   ```

### ۴-۳) وارد کردن کلیدها (متغیرها)
1. برگرد به صفحه Worker (فلش برگشت بالا) → تب **Settings** → بخش **Variables and Secrets**.
2. روی **Add** کلیک کن و این‌ها را یکی‌یکی اضافه کن (Type را **Secret** بگذار):

| نام متغیر | مقدار |
|---|---|
| `BOT_TOKEN` | توکنی که از BotFather گرفتی |
| `GROQ_API_KEY` | کلید `gsk_...` از Groq |
| `GEMINI_API_KEY` | کلید `AIza...` از Gemini (اگر گرفتی) |
| `WEBHOOK_SECRET` | یک رمز دلخواه خودت بساز، مثلاً `dabira-secret-2026-xyz` |

3. بعد از هر کدام **Save** را بزن. در پایان دوباره **Deploy** کن.

### ۴-۴) ساخت حافظه (KV) — برای قالب‌ها و پروژه‌ها
1. از منوی اصلی سمت چپ: **Storage & Databases** → **KV**.
2. **Create a namespace** → اسمش: `dabira-kv` → Create.
3. برگرد به Worker → **Settings** → **Bindings** → **Add** → **KV namespace**:
   - Variable name: `DABIRA_KV` (دقیقاً همین، با حروف بزرگ)
   - KV namespace: `dabira-kv` را انتخاب کن.
4. **Save** و بعد **Deploy**.

## مرحله ۵ — اتصال تلگرام به Worker (وب‌هوک) — ۲ دقیقه

مرورگرت را باز کن و این آدرس را در نوار آدرس بنویس (سه بخش را با مقادیر خودت عوض کن) و Enter بزن:

```
https://api.telegram.org/bot<توکن-ربات>/setWebhook?url=https://dabira.YOURNAME.workers.dev&secret_token=<همان-WEBHOOK_SECRET>
```

مثال واقعی:
```
https://api.telegram.org/bot7123456789:AAHfK9x2mP.../setWebhook?url=https://dabira.ali.workers.dev&secret_token=dabira-secret-2026-xyz
```

اگر این را دیدی یعنی همه‌چیز درست است: 🎉
```json
{"ok":true,"result":true,"description":"Webhook was set"}
```

---

## مرحله ۶ — تست! 🎙️

1. در تلگرام ربات خودت را باز کن (همان username که ساختی).
2. `/start` بزن — باید پیام خوش‌آمد دبیرا بیاید.
3. یک **ویس** بفرست و درباره یک جلسه فرضی حرف بزن.
4. چند ثانیه صبر کن — باید فایل `.md` صورت‌جلسه با تاریخ شمسی تحویل بگیری!
5. یک سؤال متنی هم بپرس — چت‌بات هوشمند هم جواب می‌دهد.

---

## مرحله ۷ — شخصی‌سازی مالک (مخصوص خودت)

### ۷-۱) معرفی خودت به‌عنوان مالک
1. در ربات دستور `/id` را بزن — یک عدد می‌دهد.
2. آن عدد را در Cloudflare به‌عنوان متغیر `OWNER_CHAT_ID` اضافه کن (مرحله ۴-۳ را تکرار کن).

### ۷-۲) آموزش «متد edge» به دبیرا
1. متن نمونه صورت‌جلسه یا شرح روش edge خودت را آماده کن.
2. در ربات بنویس: `/learn` و بعدش کل متن را پیست کن (یا روی پیام حاوی متن ریپلای کن و `/learn` بزن).
3. دبیرا ساختار را استخراج می‌کند و از آن به بعد **همه صورت‌جلسه‌ها با متد edge** نوشته می‌شوند.

### ۷-۳) اتصال به Obsidian (آرشیو خودکار هر جلسه)
ایده: فایل‌های md هر جلسه خودکار در یک مخزن GitHub ذخیره می‌شوند و Obsidian با افزونه Git آن‌ها را می‌کشد.

1. برو به **https://github.com** و (اگر نداری) ثبت‌نام کن.
2. یک مخزن جدید بساز: دکمه **New** → اسم: `obsidian-vault` → **Private** → Create.
3. برو به **https://github.com/settings/personal-access-tokens** → **Generate new token**:
   - Repository access: فقط `obsidian-vault`
   - Permissions → **Contents: Read and write**
   - Generate و توکن را کپی کن.
4. در Cloudflare این متغیرها را اضافه کن:
   - `GITHUB_TOKEN` = توکنی که ساختی
   - `GITHUB_REPO` = `نام-کاربری/obsidian-vault`
5. در Obsidian افزونه **Git** (community plugin) را نصب کن و مخزن را clone کن — از این به بعد هر جلسه خودکار در `Projects/نام-پروژه/` ظاهر می‌شود.
6. قبل از هر جلسه در ربات بزن: `/project نام-پروژه` — فایل در فولدر همان پروژه می‌رود.

## عیب‌یابی سریع

| مشکل | راه‌حل |
|---|---|
| ربات جواب نمی‌دهد | مرحله ۵ (setWebhook) را دوباره چک کن؛ آدرس Worker و توکن درست باشند |
| «خطا در پردازش: Groq 401» | کلید `GROQ_API_KEY` را اشتباه وارد کردی — دوباره Save و Deploy کن |
| «خطا: Groq 429» | سهمیه ساعتی پر شده؛ چند دقیقه صبر کن یا `GEMINI_API_KEY` اضافه کن |
| فایل بزرگ خطا می‌دهد | محدودیت تلگرام برای ربات‌ها ۲۰ مگابایت است؛ فایل را تقسیم کن |
| تنظیمات ذخیره نمی‌شود (/template و /learn اثر ندارد) | مرحله ۴-۴ (KV binding با نام دقیق `DABIRA_KV`) را چک کن |
| لاگ‌ها را کجا ببینم؟ | Worker → تب **Logs** → Begin log stream → همان لحظه پیام بفرست |
