# Vworld — ایجنت پیدا کردن متخصص 🌍

یک ایجنت که با یک درخواست ساده به زبان فارسی (یا انگلیسی)، **متخصص‌ها را در
پلتفرم‌های مختلف — تلگرام، اینستاگرام، لینکدین و وب — پیدا می‌کند** و راه
دسترسی به آن‌ها را به شما می‌دهد.

مثال:

```
$ python -m vworld "طراح گرافیک میخوام تو ساری"
```

```

============================================================

✅ 3 نتیجه پیدا شد:
```

## این ایجنت چه کاری می‌کند؟

۱. درخواست شما را می‌فهمد — **نقش شغلی**، **شهر** و **پلتفرم مورد نظر** را از
   متن استخراج می‌کند (مثلاً «طراح گرافیک»، «ساری»، «اینستاگرام»).
۲. در همه‌ی منابع فعال هم‌زمان می‌گردد (تلگرام، اینستاگرام، لینکدین، وب).
۳. نتایج تکراری را حذف و بهترین‌ها را **رتبه‌بندی** می‌کند (تطابق نقش و شهر،
   قابل‌دسترس بودن، نمونه‌کار، امتیاز، سطح تجربه، …).
۴. برای هر نفر می‌گوید **کیست، کجاست، و چطور به او دسترسی پیدا کنید** (تلگرام،
   اینستاگرام، لینکدین، تلفن/واتساپ، ایمیل، وبسایت، نمونه‌کار).

## شروع سریع (بدون هیچ تنظیماتی)

نیازی به کلید API یا نصب هیچ پکیجی نیست — به‌صورت پیش‌فرض با یک **دیتاست نمونه‌ی
آفلاین** کار می‌کند تا بتوانید همه‌چیز را همان‌جا امتحان کنید:

```bash
# لیست کردن
python -m vworld "طراح گرافیک میخوام تو ساری"

# با جزئیات کامل تماس
python -m vworld "دیجیتال مارکتر میخوام"

# خروجی JSON برای استفاده در برنامه‌های دیگر
python -m vworld "برنامه‌نویس وب ریموت" --json

# دیدن اینکه کدام پلتفرم‌ها فعال هستند
python -m vworld --sources
```

## فعال کردن جستجوی واقعی در پلتفرم‌ها

هر پلتفرم یک **کانکتور** جداست که فقط وقتی کلید مربوطه‌اش تنظیم شده باشد فعال
می‌شود. `.env.example` را به `.env` کپی کنید و مقادیر را پر کنید:

| پلتفرم | متغیرهای محیطی | پکیج لازم |
|---|---|---|
| تلگرام (جستجوی کانال/گروه عمومی) | `TELEGRAM_API_ID`, `TELEGRAM_API_HASH` | `telethon` |
| اینستاگرام (رسمی) | `INSTAGRAM_ACCESS_TOKEN` | — |
| اینستاگرام (غیررسمی) | `INSTAGRAM_USERNAME`, `INSTAGRAM_PASSWORD` | `instagrapi` |
| لینکدین + وب | `SERPAPI_KEY` | — |
| جمع‌بندی هوشمند + پارس بهتر | `ANTHROPIC_API_KEY` | `anthropic` |

نصب افزونه‌ها بر اساس نیاز:

```bash
pip install -e ".[llm]"        # جمع‌بندی هوشمند با Claude
pip install -e ".[telegram]"   # کانکتور و بات تلگرام
pip install -e ".[instagram]"  # اینستاگرام (غیررسمی)
```

هر تعداد کانکتور که فعال کنید، ایجنت هم‌زمان در همه‌ی آن‌ها می‌گردد و نتایج را
با هم ترکیب می‌کند. حتی اگر هیچ‌کدام فعال نباشند، دیتای نمونه همیشه در دسترس است.

## بات تلگرام (رابط چت)

می‌توانید مستقیماً از داخل تلگرام با ایجنت حرف بزنید:

```bash
pip install -e ".[telegram]"
export TELEGRAM_BOT_TOKEN=...   # از @BotFather
python -m vworld.bot
```

سپس در تلگرام برای بات بنویسید: «طراح گرافیک میخوام تو ساری».

## استفاده به‌صورت کتابخانه (در کد خودتان)

```python
from vworld import SpecialistFinderAgent

agent = SpecialistFinderAgent()
result = agent.search("دیجیتال مارکتر میخوام تو تهران")

for person in result.people:
    print(person.name, person.role_label, person.location_label)
    for label, value in person.contact.channels():
        print("  ", label, value)
```

## معماری

```
درخواست متنی
   │
   ▼
query_parser  ──►  استخراج نقش/شهر/پلتفرم  (+ تقویت اختیاری با LLM)
   │
   ▼
Agent  ──►  فراخوانی هم‌زمان کانکتورهای فعال
   │            ├─ Telegram   (telethon)
   │            ├─ Instagram  (graph api / instagrapi)
   │            ├─ LinkedIn   (serpapi)
   │            ├─ Web        (serpapi)
   │            └─ Demo       (آفلاین، همیشه فعال)
   ▼
حذف تکراری‌ها ──► رتبه‌بندی ──► فرمت خروجی (+ جمع‌بندی اختیاری LLM)
```

ساختار فایل‌ها:

| فایل | نقش |
|---|---|
| `vworld/query_parser.py` | فهم درخواست فارسی/انگلیسی |
| `vworld/taxonomy.py` | فرهنگ لغت نقش‌ها، شهرها، پلتفرم‌ها (به‌راحتی قابل‌گسترش) |
| `vworld/connectors/` | کانکتور هر پلتفرم |
| `vworld/ranking.py` | امتیازدهی و رتبه‌بندی شفاف |
| `vworld/agent.py` | ارکستریتور اصلی |
| `vworld/formatter.py` | خروجی برای انسان و JSON |
| `vworld/bot.py` | بات تلگرام |
| `data/demo_specialists.json` | دیتای نمونه آفلاین |

### گسترش دادن

- **نقش یا شهر جدید:** یک ورودی به `vworld/taxonomy.py` اضافه کنید.
- **پلتفرم جدید:** یک کلاس از `Connector` بسازید و در
  `connectors/__init__.py` ثبت کنید.

## نکات حقوقی و اخلاقی ⚠️

- این ابزار فقط برای جستجوی **اطلاعات عمومی** افرادی طراحی شده که خودشان
  خدماتشان را به‌صورت عمومی تبلیغ می‌کنند.
- قوانین و شرایط استفاده (ToS) هر پلتفرم را رعایت کنید. روش‌های رسمی API
  (مثل Instagram Graph API) بر روش‌های غیررسمی ترجیح دارند.
- محدودیت نرخ درخواست (rate limit) و حریم خصوصی افراد را رعایت کنید و از داده‌ها
  برای اسپم یا مقاصد نادرست استفاده نکنید.
