# دیوان (Divan) — سیستم‌عامل کسب‌وکار روی پیام‌رسان

> **دیوان:** نهاد ثبت و اداره‌ی امور در ایران باستان — جایی که تصمیم، مصوبه و حساب‌وکتاب ثبت می‌شد.

دیوان از یک بات صورت‌جلسه شروع می‌شود و به یک **سوپراپ مدیریت کسب‌وکار + پلتفرم ایجنت** می‌رسد.
تز مرکزی: **دفترچه باید خودش پر شود** — آدم‌ها جلسه می‌گذارند و حرف می‌زنند؛ دیوان همان صدا را
می‌گیرد و به ساختار تبدیل می‌کند: صورت‌جلسه، مصوبه، تسک، مسئول، مهلت.

معماری نهایی: **دیوان = مغز و دفتر ثبت. n8n = دست و پا. ایجنت‌ها = کارمندان دیجیتال.**
