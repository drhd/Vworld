# راه‌اندازی دیوان — قدم به قدم

**زمان لازم: ۱۵ تا ۲۵ دقیقه. دانش برنامه‌نویسی لازم نیست.**

---

## ⚠️ قبل از هر چیز — یک تصحیح مهم

**تلگرام سرور رایگانی برای اجرای کد بات ندارد.** این یک تصور رایج و غلط است.

آنچه تلگرام دارد فقط **دروازه‌ی API** است — یعنی آدرسی که بات شما با آن حرف می‌زند. کدِ بات همیشه باید روی یک ماشین اجرا شود: کامپیوتر خودتان، یا یک سرور.

آن چیزی که به‌عنوان «سرور خودِ تلگرام» شنیده‌اید احتمالاً **Local Bot API Server** است — که آن هم چیزی است که *شما* روی سرور خودتان نصب می‌کنید، نه تلگرام. تنها کارش برداشتن محدودیت ۲۰ مگابایتی فایل است.

**خبر خوب:** برای شروع اصلاً سرور لازم نیست. روی لپ‌تاپ خودتان بالا می‌آید. مسیر رایگان واقعی در بخش ۵ آمده.

---

## گام ۱ — نصب Docker (۵ دقیقه، یک‌بار برای همیشه)

Docker برنامه‌ای است که همه‌ی اجزای دیوان را داخل جعبه‌های جدا اجرا می‌کند، بدون آنکه چیزی روی سیستم شما نصب و شلوغ شود.

1. برو به `docker.com/products/docker-desktop`
2. نسخه‌ی ویندوز یا مک را دانلود و نصب کن
3. بعد از نصب، **Docker Desktop را باز کن** و منتظر بمان تا آیکن نهنگ سبز شود
4. برای اطمینان، ترمینال (یا PowerShell در ویندوز) را باز کن و بزن:

```bash
docker --version
```

اگر شماره‌ی نسخه دیدی، درست است.

---

## گام ۲ — روشن کردن VPN

بدون این گام هیچ‌چیز کار نمی‌کند.

تلگرام و گوگل و Groq — هر سه — از IP ایران بسته‌اند. **VPN سراسری (system-wide) روشن کن**، نه فقط روی مرورگر.

اگر پراکسی محلی داری (مثلاً روی پورت ۱۰۸۰)، به‌جای VPN می‌توانی بعداً در فایل تنظیمات بنویسی:
```
PROXY_URL=socks5://127.0.0.1:1080
```

> اگر فقط از **بله** استفاده می‌کنی، این گام لازم نیست — بله از داخل ایران باز است.

---

## گام ۳ — گرفتن دو کلید

### الف) توکن بات تلگرام

1. در تلگرام، `@BotFather` را جست‌وجو کن و بازش کن
2. بزن `/newbot`
3. یک **نام** بده (مثلاً: دیوان)
4. یک **یوزرنیم** بده که حتماً به `bot` ختم شود (مثلاً: `divan_karobar_bot`)
5. یک رشته‌ی طولانی مثل `7123456789:AAH-xxxxx` می‌دهد — **این توکن است، کپی‌اش کن**

پیشنهاد: همان‌جا این‌ها را هم بزن تا هویت بات کامل شود:
- `/setdescription` → «دفتر ثبت جلسات و مصوبات»
- `/setabouttext` → «صوت جلسه را بفرست، صورت‌جلسه و تسک تحویل بگیر»

### ب) کلید هوش مصنوعی

1. با VPN برو به `aistudio.google.com/apikey`
2. با اکانت گوگل وارد شو
3. بزن **Create API key**
4. کلید را کپی کن — کارت بانکی نمی‌خواهد

**توصیه:** یک کلید پشتیبان هم از `console.groq.com/keys` بگیر. اگر گوگل قطع شد، دیوان خودکار به آن سوییچ می‌کند.

---

## گام ۴ — اجرا (۳ دستور)

فایل پروژه را از حالت فشرده دربیاور، ترمینال را داخل همان پوشه باز کن:

```bash
# ۱. ساخت فایل تنظیمات از روی نمونه
cp .env.example .env
```

حالا فایل `.env` را با Notepad یا هر ویرایشگر متنی باز کن و دو خط را پر کن:

```
BOT_TOKEN=7123456789:AAH-xxxxx        ← توکنی که از BotFather گرفتی
GEMINI_API_KEY=AIzaSy-xxxxx           ← کلیدی که از گوگل گرفتی
```

ذخیره کن و ببند. بعد:

```bash
# ۲. ساخت و اجرا
docker compose up -d --build

# ۳. دیدن وضعیت
docker compose logs -f bot
```

اگر دیدی:
```
📜 دیوان بالا آمد — کانال: telegram — polling
```
**تمام شد.** بات زنده است.

(برای بستن نمایش لاگ `Ctrl+C` بزن — بات خاموش نمی‌شود.)

---

## گام ۵ — اولین استفاده

1. در تلگرام بات خودت را باز کن و `/start` بزن
2. **اولین نفری که این کار را کند، سوپر ادمین می‌شود** و workspace ساخته می‌شود
3. نام تیم/سازمان را بفرست
4. یک **کد دعوت** می‌گیری — این را به بقیه‌ی اعضا بده تا با آن عضو شوند
5. یک ویس کوتاه (مثلاً یک دقیقه صحبت دونفره) بفرست و مسیر کامل را ببین

**قبل از تست، این چهار مورد را بساز تا بات معنا پیدا کند:**
- یک پروفایل (👤 پروفایل‌ها ← ساخت)
- یک موضوع (📁 موضوعات ← ساخت)
- یک پروژه (🗂 پروژه‌ها ← ساخت — خودکار ۴ فاز و ۴ لایه می‌سازد)
- بعد ویس بفرست و به همان پروفایل وصلش کن

---

## گام ۶ — راه‌اندازی آرشیو خودکار (اختیاری ولی توصیه‌شده)

این کاری است که دیوان را از یک بات به یک آرشیو تمیز تبدیل می‌کند:

1. یک **سوپرگروه** بساز و در تنظیماتش **Topics** را روشن کن
2. بات را به گروه اضافه کن و **ادمینش کن** ← بدون ادمین، ارسال در تاپیک و پین کار نمی‌کند
3. برای هر پروفایل/موضوع یک تاپیک بساز
4. داخل همان تاپیک بنویس:
   ```
   /bind p1
   ```
   (`p` برای پروفایل، `t` برای موضوع — شماره را از داخل بات ببین)

از این به بعد صورت‌جلسه‌ها و رونوشت‌های آن پروفایل خودکار همان‌جا آرشیو و پین می‌شود.

---

## ۵. کجا اجرا کنم؟ — گزینه‌های رایگان واقعی

### گزینه ۱ — لپ‌تاپ خودت (پیشنهاد برای شروع)
- **هزینه: صفر. ثبت‌نام: هیچ. راه‌اندازی: همین الان.**
- عیب: با خاموش‌شدن لپ‌تاپ، بات هم می‌خوابد
- **مناسب برای:** کل دوره‌ی تست میدانی

### گزینه ۲ — Oracle Cloud Always Free
- سرور واقعی و همیشه‌رایگان با منابع سخاوتمندانه (چند هسته و چند گیگ رم)
- کارت بانکی برای تأیید هویت می‌خواهد — از ایران معمولاً دردسر دارد
- **مناسب برای:** وقتی بات باید ۲۴ ساعته زنده باشد

### گزینه ۳ — Koyeb
- مزیت کلیدی: **حالت خواب ندارد** — بات همیشه بیدار است
- معمولاً بدون کارت بانکی
- ⚠️ در بهمن ۱۴۰۴ توسط Mistral AI خریداری شد؛ شرایط لایه‌ی رایگان ممکن است تغییر کند — قبل از اتکا چک کن

### ❌ گزینه‌هایی که برای دیوان مناسب **نیستند**
- **Render:** سرویس رایگان بعد از ۱۵ دقیقه بی‌کاری می‌خوابد و **دیتابیس رایگانش بعد از ۳۰ روز منقضی و حذف می‌شود** — برای محصولی که داده‌ی مشتری نگه می‌دارد، خودکشی است
- **Railway و Fly.io:** دیگر واقعاً رایگان نیستند؛ مدل اعتبار/مصرفی دارند

### 🇮🇷 نکته‌ی مهم برای سرور ایرانی
اگر روی هاست ایرانی اجرا کنی، به `api.telegram.org` نمی‌رسی (فیلتر است) — یعنی **نسخه‌ی تلگرام کار نمی‌کند** مگر با پراکسی.
اما **نسخه‌ی بله بی‌نقص کار می‌کند** و حتی سریع‌تر است.

**الگوی پیشنهادی:** نسخه‌ی بله روی سرور ایرانی + نسخه‌ی تلگرام روی سرور خارجی — هر دو به یک دیتابیس وصل، یک محصول، دو در ورودی.

---

## ۶. اجرای نسخه‌ی بله

بله رسماً اعلام کرده API‌اش با تلگرام سازگار است، پس همین کد بدون تغییر روی بله هم اجرا می‌شود.

1. در اپلیکیشن بله، `BotFather` را جست‌وجو کن و یک بازو (بات) بساز
2. توکن را در `.env` بگذار: `BALE_TOKEN=...`
3. اجرا کن:
   ```bash
   docker compose --profile bale up -d
   ```

حالا دو بات روی یک دیتابیس مشترک کار می‌کنند.

⚠️ **انتظار واقع‌بینانه:** «سازگار» یعنی اکثر متدها یکی‌اند، نه همه. تاپیک‌های فوروم احتمالاً در بله نیست — کد این را تشخیص می‌دهد و به‌جای کرش، آرشیو را در خود گروه می‌گذارد. بعد از تست میدانی، جدول قابلیت‌ها در `app/channels.py` را با واقعیت به‌روز کن.

---

## ۷. بکاپ

**خودکار:** سرویس `backup` هر ۲۴ ساعت یک نسخه‌ی فشرده در پوشه‌ی `backups/` می‌گذارد و نسخه‌های قدیمی‌تر از ۱۴ روز را پاک می‌کند. کاری لازم نیست بکنی.

**دستی از داخل بات:** دکمه‌ی 📦 خروجی سه گزینه می‌دهد:
- خروجی یک **پروفایل** → ZIP شامل همه‌ی جلسات، صورت‌جلسه‌ها، رونوشت‌ها، تسک‌ها و کامنت‌های آن شخص
- خروجی یک **موضوع** یا **پروژه** → همان ساختار
- **بکاپ کامل workspace** (فقط مدیر)

هر ZIP یک فایل `raw_data.json` هم دارد که برای انتقال به CRM یا هر سیستم دیگری آماده است.

**توصیه‌ی جدی:** پوشه‌ی `backups/` را ماهی یک‌بار جای دیگری کپی کن. بکاپی که روی همان ماشین است، بکاپ نیست.

## ۸. دستورهای روزمره

```bash
docker compose logs -f bot        # دیدن لاگ زنده
docker compose restart bot        # ری‌استارت بات
docker compose down               # خاموش کردن همه
docker compose up -d              # روشن کردن دوباره
docker compose up -d --build      # بعد از تغییر کد
```

## ۹. وقتی کار نکرد

| نشانه | علت محتمل | راه‌حل |
|---|---|---|
| `توکن کانال تنظیم نشده` | `.env` خالی است | توکن را در `.env` بگذار، `docker compose up -d --build` |
| بات پیام نمی‌دهد | VPN خاموش است | VPN سراسری روشن کن، `docker compose restart bot` |
| `Connection refused` | Docker Desktop بالا نیامده | نهنگ سبز شود، دوباره اجرا کن |
| پردازش صوت خطا می‌دهد | کلید هوش مصنوعی غلط یا سهمیه تمام | کلید را چک کن؛ کلید Groq را هم اضافه کن |
| فایل >20MB رد می‌شود | سقف API استاندارد تلگرام | `docker compose --profile bigfiles up -d` |
| در تاپیک آرشیو نمی‌شود | بات ادمین گروه نیست | بات را ادمین کن |
| گوینده‌ها تفکیک نشدند | Groq جواب داده، نه Gemini | طبیعی است — Groq دیاریزیشن ندارد |

**برای گزارش هر باگ، این را بفرست:**
```bash
docker compose logs --tail=80 bot worker
```

## ۱۰. یادآوری امنیتی

🔴 **در دوره‌ی تست، جلسه‌ی محرمانه پردازش نکن.**

لایه‌ی رایگان گوگل اجازه دارد داده‌ی ارسالی را برای آموزش مدل استفاده کند. برای تست داخلی اشکالی ندارد؛ برای جلسه‌ی قرارداد و مذاکره‌ی مشتری نه. قبل از اولین استفاده‌ی واقعی روی داده‌ی محرمانه، باید به لایه‌ی پولی مهاجرت کنی — که در معماری فقط یک تغییر تنظیمات است.
